\begin{center}
\textbf{\Large ABSTRACT}
\end{center}

\vspace{0.3in}
\begin{spacing}{1.5}

\noindent In recent years, digital financial transactions have experienced explosive growth. Millions of daily micro-transactions are processed digitally across multiple platforms, creating a significant challenge for personal financial management (PFM). Traditional manual tracking methods lead to user fatigue, while existing automated mobile apps often rely on reading private SMS messages or fail to support password-protected bank statements. Furthermore, conventional PFM tools present static tables without providing actionable, context-aware financial guidance.

\noindent This project presents \textbf{Finlytics} (FinTracker), a privacy-focused, full-stack personal finance tracker designed to bridge the gap between raw transaction data and meaningful financial decision-making. Built using Spring Boot, MySQL, Apache PDFBox, Chart.js, and the Groq API (LLaMA 3.1 8B Instant model), Finlytics automates the parsing of password-protected bank PDFs (such as SBI YONO) and multi-line Google Pay UPI statements using advanced Regular Expressions.

\noindent To classify unorganized transaction narratives, the system incorporates a dynamic hybrid categorization engine combining persistent user-defined rules and heuristic keyword dictionaries. An interactive web dashboard renders real-time financial analytics, budget tracking with overspending alerts, and visual spending trends. Furthermore, an AI-driven financial advisor module aggregates 30-day spending trends to generate personalized, context-aware monetary recommendations. Operating entirely under user control with session-based authentication and isolated storage, Finlytics offers a robust, privacy-centric solution for modern personal financial management.

\vspace{0.2in}
\noindent \textbf{KEYWORDS:} Personal Finance Management, Bank Statement Parsing, Apache PDFBox, Hybrid Categorization, Chart.js Analytics, Large Language Models (LLM), Groq API, Data Privacy.

\end{spacing}
